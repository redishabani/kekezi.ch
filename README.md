# Kekezi Smart Mobility

Kekezi Smart Mobility is a multilingual, static business website for a premium chauffeur and transfer service based in Zürich, Switzerland. The site presents the company’s core offerings, fleet, pricing, and contact details in a polished, conversion-focused layout.

## Website target owner

This website is intended for **Kekezi Smart Mobility**, a transport and mobility service provider serving:
- private customers
- business travelers
- VIP clients
- hotels
- schools and institutions
- event and group transport customers

The site is built to promote premium mobility services in Zürich and throughout Switzerland, while also supporting nearby European routes and airport transfers.

## What the website does

The website is designed to:
- introduce Kekezi Smart Mobility and its premium mobility services
- present key service categories such as airport transfers, business/VIP rides, event transport, and school transport
- show indicative pricing for selected services
- showcase available vehicle classes and fleet options
- make it easy for visitors to call, email, or find the business location
- support multiple languages for a broader audience

## Technical details

- **Project type:** static website
- **Primary language:** HTML
- **Frontend approach:** single-page layout with embedded CSS and JavaScript
- **Language support:** German, English, French, and Italian
- **Responsive design:** includes mobile-friendly layouts and a fixed mobile action bar
- **Navigation:** anchored sections with smooth scrolling behavior
- **Contact actions:** telephone links, email links, and Google Maps embed
- **Assets:** images and branding files stored under `public/img/`
- **Pages:** includes the main landing page, alternate versions, a vCard page, and a custom 404 page

## Repository structure

Typical content includes:
- `public/index.html` — main homepage
- `public/index_bis.html` — alternate homepage/version
- `public/vcard.html` — digital contact card
- `public/404.html` — custom error page
- `public/eng/` — English version
- `public/fra/` — French version
- `public/ita/` — Italian version
- `public/img/` — images and visual assets

## Features

- Premium transport service landing page
- Fleet showcase with Mercedes-Benz vehicle classes
- Service overview for business, VIP, airport, event, and school transport
- Pricing information for selected routes and services
- Contact section with address, phone, email, and map
- Language switching between supported locales
- Mobile-first call-to-action buttons

## Notes

This repository appears to be a fully static marketing site rather than a server-side application. It can be hosted on any static hosting platform such as GitHub Pages, Netlify, or similar services.
